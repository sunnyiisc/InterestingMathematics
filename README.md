# Interesting Mathematics Questions
This is the repository of 100 questions on Mathematics which are must solve for any Engineer.

Questions are self made or are taken reference from somewhere, the following are the analysis steps on the mathematics questions for learning purpose.
1. Learn the basic concepts seeing the question.
2. Solve the question, re-learn the concepts missed in step-1.
3. Solve the question in any programming software. (here I am using [python](https://www.python.org) for the solution)
4. Validate software results with solution in step 2. If not matching re-iterate everything.
